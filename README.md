## 🚀 Featured Projects

### 🧠 Voca English Memory

**Learn vocabulary the way memory champions memorise.** Built around the **Memory Palace (Method of Loci)** technique: AI places each word in a room of your own mental house with a vivid image, then draws the **memory journey** you walk to recall them.

- **Tech:** Next.js • TypeScript • Supabase • Google Gemini
- **Live Demo:** [voca-english-memory.vercel.app](https://voca-english-memory.vercel.app) · **Source:** [voca-english-memory](https://github.com/thanhthaonguyen680/voca-english-memory)

### 🛍️ KHA — Fashion E-commerce Store

A production online store for a fashion brand, with a full **admin panel**: catalog, cart, checkout and payments on the storefront; products, orders, customers and site settings on the admin side.

- **Tech:** Next.js • TypeScript • Tailwind CSS • Supabase
- **Live Demo:** [khaofficial.vn](https://khaofficial.vn/) · **Source:** private repository

### 📋 Task Management System

A business operations platform a company runs its daily work on: task boards with subtasks, photo/video proof and QR scanning, plus attendance, leave, payroll and bonus management with Excel/PDF exports.

- **Impact:** Manages **2,000+ tasks** in production, with daily visit tracking.
- **Tech:** Next.js • TypeScript • PostgreSQL • Tailwind CSS • Python
- **Source:** private repository

### 🎸 HopAmChuan Crawler

An ad-free guitar chord viewer: crawls the songs I pick, uses an LLM to parse clean lyrics and chords, with key transposing and chord fingering diagrams.

- **Tech:** TypeScript • Node.js • PostgreSQL • Google Gemini
- **Live Demo:** [hopamchuan-crawler.vercel.app](https://hopamchuan-crawler.vercel.app) · **Source:** [hopamchuan-crawler](https://github.com/thanhthaonguyen680/hopamchuan-crawler)

### 🎓 SDET Bootcamp
